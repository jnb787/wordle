# wordle
Python wordle game that runs in the command line

## How to run
cd int project route and run the followinh command
```bash
python main.py
```

## How to play
- The game will run until you guess the word or run out of guesses.
- The game will print out the board after each guess.
- A green letter indicates the correct letter in the correct position.
- A yellow letter indicates the correct letter in the wrong position.
- If you fail to guess the word, the game will print out the word and you will lose.
